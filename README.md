# FarAway

FarAway is an experimental LOD rendering mod for Minecraft Java Edition 26.3.
In singleplayer, it uses the world seed to generate lower-detail terrain
beyond the game's render distance.

## Getting started

FarAway requires Fabric Loader, Fabric API, and Sodium 0.9.2. See
[INSTALL.md](INSTALL.md) for build and installation instructions.

Open the settings in-game with `/faraway settings` or `/fa settings`.
